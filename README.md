# release-layer

> **Note:** `release-layer` is a working name, not final.

The release layer of an AI trust ecosystem: safe shipping of AI changes (prompts, models, configs) via shadow evaluation and judged promotion.

**Status:** v0 wedge in development — a shadow-runner CLI that runs a candidate against historical inputs, judges candidate vs. production, and emits a promote/block report. See [PLAN.md](./PLAN.md) for the product thesis and roadmap.
