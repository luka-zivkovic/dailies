# Claude repository context

Read and follow [`AGENTS.md`](AGENTS.md) before auditing, planning, or changing
this repository. In particular, read `PRODUCT.md` and ADR statuses before
using README, roadmap, CLI copy, comments, or current code to infer product
intent.

Every product-scope claim in an audit should be identified as `TARGET`,
`CURRENT`, or `ASSUMPTION`. Do not implement a proposed ADR without explicit
approval. Treat `docs/positioning.md` as dated market context, not product
authority.
